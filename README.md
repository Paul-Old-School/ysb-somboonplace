# อยู่สมบูรณ์ เพลส (YSB) — เว็บไซต์สไตล์เว็บจองที่พัก (Local Build)

โฟลเดอร์นี้บรรจุไฟล์เว็บไซต์ฉบับสมบูรณ์สำหรับเปิดดูและเตรียมเผยแพร่ในเครื่อง (ยังไม่ได้เชื่อมต่อโฮสต์ โดเมน หรือบริการเสียเงิน)

## โครงสร้างไฟล์

- `index.html` — หน้าแรก (ส่วนบนสุด + กล่องค้นหา/สอบถามห้องว่างรายวัน-รายเดือน + การ์ดห้องพัก + สรุปยอด 8,400 + ส่วนกลาง + ทำเล + วิธีจอง + เงื่อนไข + ร้านซักผ้า 24 ชม. + คำถามพบบ่อย 8 ข้อ + ติดต่อ)
- `rooms.html` — หน้าห้องพักและราคา (กรองรายวัน/รายเดือน + ตารางเปรียบเทียบแบบห้อง + ยอดวันทำสัญญา 8,400 + เครื่องมือคำนวณค่าห้องรายวันเบื้องต้น + ตึกอื่น 1 บรรทัด + ช่องรูปห้องพัก)
- `location.html` — หน้าทำเลและแผนที่ (ที่อยู่ จุดสังเกต ระยะทางสถานที่ใกล้เคียง ช่องแผนที่ Google Maps ส่วนกลางและความปลอดภัย)
- `terms.html` — หน้าวิธีจอง เงื่อนไขการเช่า และคำถามที่พบบ่อย (ขั้นตอนจอง เงื่อนไขตามเอกสารเจ้าของครบทุกข้อ และ FAQ 8 ข้อพร้อม `FAQPage` JSON-LD)
- `laundry.html` — หน้าร้านซักผ้า 24 ชั่วโมง (บล็อกสีส้มแยกชัดเจน เวลาเปิด 24 ชม. ช่วงเวลาพนักงานให้บริการ ช่องรูปหน้าร้านและในร้าน)
- `styles.css` — สไตล์หลัก (Mobile-first 320px+, Prompt + Sarabun, ผ่าน WCAG AA)
- `app.js` — สคริปต์เสริม (แท็บค้นหา, นับจำนวนคืน, คัดลอกข้อความส่งไลน์, กรองห้องพัก, คำนวณค่าห้องรายวัน, เปิด/พับคำถามพบบ่อย, เมนูมือถือ)
- `assets/favicon.svg` — ไอคอนตรา YSB ชั่วคราว
- `robots.txt` — ตั้งค่าปิดการเก็บดัชนีชั่วคราวก่อนเผยแพร่จริง
